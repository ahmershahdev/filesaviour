# Security policy

Report vulnerabilities privately to **support@ahmershah.dev** with "Security" in the subject.
Include steps to reproduce and impact. Please don't open public issues for security problems.

We acknowledge within 2 working days and aim to fix critical issues within 7 days.

In scope: filesaviour.ahmershah.dev, this repository's code, the processing engine.
Out of scope: denial-of-service volume tests, social engineering, third-party services.
